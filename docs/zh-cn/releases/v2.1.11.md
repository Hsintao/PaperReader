# PaperReader v2.1.11

> 下载前请阅读[使用说明](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/user_instruction.md)。[English release notes](../../releases/v2.1.11.md)

v2.1.11 修复首次点击对照高亮不显示的问题，支持在阅读器内查看批注笔记，并为每个 PDF 提供竖向图表导航。

## 更新内容

- **对照高亮**：文字层就绪后立即绘制并居中显示匹配文字。跨页段落优先定位所选片段，统一处理 PDF 连字；未找到匹配文字时显示提示。
- **批注预览**：点击工具栏“批注笔记”、已有高亮，或右键“查看批注”，即可查看引用文字与备注。面板支持定位原句、删除和导出 Markdown 笔记。
- **图表导航**：半透明竖排缩略图列表浮动在各 PDF 区域左侧，可独立滚动。TeX 项目按主文件及引用文件中的 Figure/Table 顺序展示，包含一个浮动环境中的多个表注。缩略图来自实际编译结果，支持矢量插图和 LaTeX 表格；原文与译文分别定位各自的页码。
- **独立保存密钥**：大模型与 MinerU Key 留空或仅含空格时均保留原值，各自的删除选项仅清除对应密钥。缺少 MinerU Key 不妨碍保存大模型设置、处理 TeX 和问答；上传 PDF 时检查所选解析器配置。
- **默认使用 MinerU**：新配置默认选择 MinerU，已保存的解析器选择继续生效，也可手动选择本地解析。

## 升级

保留原有 `DATA_DIR`、数据库与 `AUTH_SECRET_KEY`。已有账号、批注、密钥、论文和翻译断点继续可用，无需手动迁移数据库。PDF 编译仍需本机 TeX 环境。

## 验证

- 后端回归覆盖密钥独立更新和删除、解析器默认值、TeX 文件引用顺序、多个表注及双 PDF 页码定位。
- Denoise 的 PDF 和 TeX 压缩包验证得到 11 个 Figure、13 个 Table；原文为 18 页，TeX 项目使用声明的 `pdflatex` 编译通过。
- Chromium 验证首次高亮、跨页片段匹配、批注预览、图表跳转和窄阅读区域；前端执行类型检查及生产构建。
- 发布流程运行跨平台后端测试，以及 Windows/macOS 打包和成品启动检查。

## 限制

对照语句依赖已保存的双语对齐及段落内的比例位置；缺少可靠对齐或可选文字时可能需要选择更完整的语句。TeX 缩略图优先按 PDF 浮动体锚点裁剪，无锚点时显示整页预览。本地回归不调用外部 LLM 或 MinerU 服务。
