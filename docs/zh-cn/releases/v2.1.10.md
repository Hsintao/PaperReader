# PaperReader v2.1.10

> 📖 **下载前请先阅读[用户说明书](../../user_instruction.md)**：安装、首次配置与使用说明。[English release notes](../../releases/v2.1.10.md)

PaperReader v2.1.10 提高了 LaTeX 自动修复的完成率。编译失败现在被当作可迭代修复的问题处理：每次尝试后，最新的编译结果都会反馈给模型，直到译文编译通过或达到五轮上限。

## 新特性

- **没有安全修复窗口也会继续诊断。** 日志缺少可用的 `l.<n>` 或文件行号时，仍会把编译失败信息和当前 TeX 源码交给模型。
- **下一轮修复使用上一轮编译反馈。** 初始编译错误、诊断、已应用补丁、被拒绝的响应原因和后续编译错误都会传递给下一轮。
- **修复范围覆盖真实的 LaTeX 根因。** 可以修正导言区定义、添加普通宏包声明、纠正宏，或替换完整的损坏环境；原先过窄的控制序列白名单和两轮上限已取消。
- **保留源码内容。** 补丁必须使用完整且准确的源代码行；仍拒绝新增文件路径和 shell/file-I/O 命令，并限制总修改量，禁止大段删除论文内容。每轮应用补丁前都会保存备份，且不会覆盖更早的备份。
- **更能容忍模型返回格式。** 严格 JSON 可以包在 Markdown JSON 代码块中；格式错误或被拒绝的响应会把具体原因反馈给下一轮。

## 兼容性

这是向后兼容版本。既有 `DATA_DIR`、SQLite 数据库、账号设置、服务商密钥、TeX 工程和已完成的翻译检查点都可继续使用，无需手动迁移数据库。生成译文 PDF 仍需要安装 TeX Live、`latexmk` 和所选 TeX 引擎。
