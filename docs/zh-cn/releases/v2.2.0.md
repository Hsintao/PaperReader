# PaperReader v2.2.0

## 忠实原稿的译文排版

译文 PDF 不再是整篇重排的 LaTeX 文档：每个译文块都钉回原稿段落的坐标，页面尺寸与页数保持与原稿一致，因此左右两栏逐页对齐。

- 字号、字重、对齐方式与行距都从原稿实测得到，不再硬编码。
- 放不下时按顺序让步：先用块下方留白 → 只缩小本块字号（不低于原字号的 0.5 倍）→ 紧随其后的丢失区域确实是本段落的尾巴时续排过去 → 最后回退为原稿内容并记账。
- 每页统一一个正文字号与一个行距，避免个别密集块把整页排版带偏。

## 沿用原稿素材，不重建

- 图片、块级公式、图注、表注与页眉页脚直接沿用原稿，保持矢量质量、位置与文字层。
- 表格保留原稿矢量线条，只替换已翻译的单元格文字；放不下时先缩到 0.6 倍，再回填英文原文，最后留空并告警。
- 行内公式从原稿裁取后按当前块的字号比例嵌入译文行内。
- 图注与表注不进入翻译队列，不再消耗翻译额度，也不会产生"翻译失败"告警。

## VLM 解析的行内公式补齐几何

MinerU 的 VLM 后端只返回 `content_list_v2.json`，没有 `middle.json`；而 content list 里行内公式只有 LaTeX、没有 bbox。这类公式无法从原稿裁出，于是凡是含行内公式的段落都只能保留英文——在公式密集的论文里就会整页不翻译。现在改为从模型输出（`*_model.json`）补齐这些框：x/y 分别按页宽页高缩放，两个文件公式数量不一致时先按 LaTeX 归一化匹配；仍未定位到的公式在重建段落时略去，而不是让整块保留英文。

## 跨区域的段落

解析器把同一段拆成相邻两块（跨栏或跨页）时，现在按一整段翻译一次，再把译文按原文两半的长度比例分配回各自区域，并在附近标点处断开；两半（含其中的行内公式）各留在自己的区域内，不会挤进同一块。区域位置由原稿文字层与解析文本的对齐得到，因此两段之间隔着插图、图注甚至整页也不会把段落拆断，解析器框小了的地方改用它真正画出的文字。

## 校验与降级

- 合成后逐页校验：应当被移除的原稿字符必须消失，被替换块之外的字符必须仍然存在。第一项失败的块回退为原稿内容；第二项失败的页整页回退为原稿页。
- 校验不通过的翻译片段原地保留原稿内容，并写入日志，不阻塞整篇导出。
- 全部页失败或失败页超过 3 页且达 20% 时直接报错，不产出半成品。

## 移除 TeX 依赖

译文不再经过 LaTeX：`translated.tex`、浏览器内 TeX 编辑器、重新编译接口与 LaTeX 自动恢复都已删除，同时去掉 `LATEXMK_PATH` 设置与 TeX Live 前置要求。生成译文 PDF 现在只需要宿主机安装中文字体（macOS：Songti SC；Windows：SimSun；Linux：fonts-noto-cjk），并新增 `reportlab` 依赖。

设置 `LAYOUT_DEBUG=true` 会额外产出 `layout-debug.pdf`，在原页上标出渲染器识别出的块类别，并用虚线框标出实际沿用的图注区域。
