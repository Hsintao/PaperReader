# PaperReader v2.1.9

> 📖 **Read the [User Guide (中文)](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/user_instruction.md) before downloading** — installation, first-run setup, and usage. [中文发布说明](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/zh-cn/releases/v2.1.9.md)

PaperReader v2.1.9 upgrades the reading experience to match mature paper readers: search, annotations, position memory, and synced scrolling are now built in, AI answers stream with clickable citations, and the PDF renderer loads pages on demand so long papers stay fast.

## What's new

- **In-document search (Ctrl/Cmd+F).** A search bar in each pane finds every occurrence across the whole document (CJK included), shows an x/y counter, and navigates matches with Enter / Shift+Enter; the current match is centered and highlighted distinctly.
- **Persistent annotations with Markdown note export.** Selected text can be highlighted in four colors with an optional note; annotations are stored per account in SQLite, repainted automatically when a document reopens or a page scrolls back into view, and export as a bilingual Markdown reading-notes file (original quote, aligned translated counterpart, and your notes per page).
- **Reading-position memory.** The reader reports the current page and scroll position (debounced) and restores it on reopen, so a paper continues where you left it.
- **Synced dual-pane scrolling.** Scrolling one pane scrolls the counterpart by the same document position, toggleable per pane via the link icon and guarded against feedback loops. The bilingual counterpart highlight also improved: it now lands on the sentence corresponding to your selection instead of always the beginning of the matched block, and when several blocks contain the same phrase, the one nearest the source page wins instead of the first occurrence in the document.
- **Figure gallery.** Every figure and table parsed out of the paper (MinerU content list or the local parser's extraction checkpoint) appears as a thumbnail strip in the pane toolbar; clicking a card jumps to its page. LaTeX projects list their included graphics instead.
- **Selection-anchored AI and citation jumps.** The selection menu gains "问 AI": the chat request carries the selected text, and the backend grounds the answer in the matched bilingual block plus its neighbors before the general retrieval. Answers stream token by token over SSE, and [P#] citations render as clickable badges that jump to the cited passage (switching documents when the citation points elsewhere in the library).
- **Library-wide full-text search.** The sidebar gains a search box that scans every parsed document's original and translated text and lists matches with snippets; clicking a hit opens the document and highlights the passage.
- **Metadata and BibTeX export.** Finished documents are enriched (best-effort, non-blocking) with title/authors/year/venue via Semantic Scholar, shown in the sidebar, and exportable as BibTeX from the document context menu. LaTeX projects with their own `.bib` file get that file verbatim.
- **On-demand PDF rendering.** Scroll mode now mounts only the pages near the viewport (placeholders keep every page's exact size, so scroll anchoring, the pinch-zoom engine, and page numbers behave as before). Memory and first paint no longer scale with page count, and zoom re-renders only visible pages. Outlines prefer the section structure produced during parsing and fall back to the text-layer heuristic only when no structure exists.
- **microtype no longer aborts translated XeLaTeX builds.** Venue templates that pair `\usepackage{microtype}` with Type1 Times (NeurIPS sets `\renewcommand{\rmdefault}{ptm}` in the style file) fail under XeLaTeX with `Cannot use XeTeXglyph with ptmr8c` once the TS1 companion font is substituted — the first `itemize` bullet is enough to trigger it. The translated preamble now switches microtype's protrusion feature off after every preamble package and `\microtypesetup` call, wherever microtype was loaded from; protrusion only subtly refines margins, so translated PDFs render without it.

## Compatibility

Backward-compatible release with no manual data migration: SQLite adds reading-position and metadata columns plus an `annotations` table on first start. The blocking chat endpoint is retained alongside the new SSE endpoint. TeX Live with `latexmk` and XeLaTeX remains required for translated PDF generation.
