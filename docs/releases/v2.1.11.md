# PaperReader v2.1.11

> 📖 **Read the [User Guide (中文)](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/user_instruction.md) before downloading** — installation, first-run setup, and usage. [中文发布说明](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/zh-cn/releases/v2.1.11.md)

PaperReader v2.1.11 makes counterpart highlighting respond on the first click, adds annotation previews, and provides a vertical figure navigator for each PDF pane.

## What's new

- **Reliable counterpart highlighting.** The reader applies highlights when the text layer is ready and centers the matched text. Selected fragments take precedence over a paragraph's opening when the paragraph spans pages. PDF ligatures are normalized for matching; an unmatched selection shows a message.
- **Read notes in the reader.** Open the annotation panel from the toolbar, click an existing highlight, or choose “查看批注” from its context menu. Quotes and notes are visible together, with locate, delete, and Markdown export actions.
- **Figures and tables beside the PDF.** A translucent vertical strip floats along the left edge of each pane and scrolls independently. TeX galleries follow Figure/Table environments in the main document and included sources, including multiple captions in one float. Thumbnails render compiled content, including vector figures and LaTeX tables. Original and translated PDFs have independent caption locations.
- **Independent provider credentials.** Blank or whitespace-only key fields preserve the saved key. The two delete controls affect only their own credential. Missing MinerU credentials do not block saving LLM settings, TeX processing, or chat; PDF upload checks the selected parser's credentials.
- **MinerU by default.** New configurations use MinerU. Existing explicit parser choices remain unchanged, and local extraction remains available.

## Compatibility

Existing accounts, annotations, provider settings, documents, and translation checkpoints remain usable. Keep the same `DATA_DIR` and `AUTH_SECRET_KEY`. No manual database migration is required. PDF compilation requires a working TeX installation.

## Verification

- Backend regression tests cover independent key updates, explicit key deletion, parser defaults, TeX inclusion order, multiple table captions, and independent PDF page locations.
- The local Denoise PDF and LaTeX archive check identifies 11 Figures and 13 Tables in an 18-page paper. The archive compiles with its declared `pdflatex` engine.
- Chromium checks cover first-click highlighting, cross-page fragment matching, annotation preview, figure/table navigation, and a narrower reader pane. TypeScript checking and the production frontend build are included.
- The release workflow tests the backend across Windows, macOS, and Linux, builds both desktop applications, and smoke-tests the packaged executables before publication.

## Limitations

Counterpart sentence selection uses the saved bilingual alignment and proportional position inside a block. Papers without usable alignment or selectable text may require a longer selection. TeX thumbnails use PDF float anchors where available and otherwise show a page preview. The local regression does not call external LLM or MinerU services.
