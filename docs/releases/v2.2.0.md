# PaperReader v2.2.0

## Page-faithful translation layout

The translated PDF is no longer a reflowed LaTeX document. Every translated
block is now pinned to the source paragraph's coordinates on a page that keeps
the original page size and page count, so the two panes stay aligned page for
page.

- Font size, weight, alignment and line spacing are measured from the source
  page instead of being hard-coded.
- When a translation does not fit, the block first uses the whitespace below
  it, then shrinks only itself (never below half the source size), then
  continues into a region the parser dropped when that region really is the
  paragraph's own tail, and finally keeps the source wording and records it.
- One body size and one line spacing are applied per page so a single dense
  block cannot make the page look uneven.

## Source artwork is reused, not rebuilt

- Figures, block formulas, captions, table notes and running heads are taken
  from the original page untouched, so they keep their vector quality, their
  position and their own text.
- Tables keep the original vector rules; only translated cell text is
  replaced. A cell that does not fit first shrinks to 0.6x, then falls back to
  the English original, then is left blank with a warning.
- Inline formulas are cropped from the source page and embedded in the
  translated line at the block's font size.
- Captions and table notes never enter the translation queue, so they no longer
  consume translation budget or raise "translation failed" warnings.

## VLM parses keep their formulas

MinerU's VLM backend returns `content_list_v2.json` without a `middle.json`,
and the content list carries inline-formula LaTeX but no boxes. Those formulas
could not be lifted off the source page, so every paragraph that contained one
kept its English — on a formula-dense paper that left whole pages untranslated.
The model output (`*_model.json`) now supplies the missing boxes; X and Y are
scaled per axis, and a page whose formula count differs between the two files
falls back to matching by LaTeX. A formula that is still unlocated is left out
of the rebuilt paragraph rather than keeping the whole region in English.

## Paragraphs split across regions

When the parser reports one paragraph as two adjacent regions (a column or page
break), it is translated as a single paragraph — one request, one wording — and
the translation is distributed back over those regions in proportion to the
source halves, snapping to nearby punctuation. Each half stays in its own
region, formulas included, instead of pooling in one box. The regions are found
by aligning the parsed wording against the page's own text layer, so a gap
between two regions — a figure, a caption block or a whole page — does not break
the paragraph in two, and the wording the page really draws replaces a box that
the parser cut short.

## Verification and degradation

- After composition each page is verified: source characters that should have
  been removed must be gone, and characters outside the replaced blocks must
  still be present. A block that fails the first check reverts to its source
  wording; a page that fails the second falls back to the untouched source
  page.
- A translation that cannot be validated keeps its source wording instead of
  failing the document, and the pipeline records it in the log.
- A document whose pages all fail, or that has more than three failed pages
  and at least 20%, reports an error instead of publishing a half-translated
  file.

## TeX is gone

The translated output no longer goes through LaTeX: `translated.tex`, the
in-app TeX editor, the recompile endpoints and the automatic LaTeX recovery
loop were removed, along with the `LATEXMK_PATH` setting and the TeX Live
requirement. Translated-PDF generation now needs a Chinese font on the host
(macOS: Songti SC; Windows: SimSun; Linux: fonts-noto-cjk) and the new
`reportlab` dependency.

`LAYOUT_DEBUG=true` additionally writes `layout-debug.pdf`, which marks the
source page with the block categories the renderer detected and outlines the
caption regions it reuses.
