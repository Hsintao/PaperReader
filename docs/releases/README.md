# Release notes

These are the per-version release notes for PaperReader, kept as the historical record of each release.

Parser and provider references in them — SoMark, MinerU and the built-in local parser — describe versions that have since been replaced: parsing, translation and translated-PDF layout now run in the PDFMathTranslate-next worker. The current configuration is documented in [DEVELOPMENT.md](../DEVELOPMENT.md) and [UPGRADING.md](../UPGRADING.md).
