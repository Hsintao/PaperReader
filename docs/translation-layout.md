# 译文排版设计

> 本文只讲译文怎么排，不讲实现。设计取舍与实测依据见

## 一、总原则

> **译文钉在原文段落的坐标上；字号、字重、对齐以原稿实测为准；装不下时按「先吃留白 → 再缩字 →
> 再续排 → 最后截断」的顺序让步；图片、公式、图注一律不重排，直接沿用原稿；表格保留矢量只换字。**

不追求译文与英文逐行对齐，只保证：段落起点、栏宽、图表位置、页面留白与原稿一致，且译文完整不丢。

## 二、页面骨架

- 一页原文对应一页对照页，不做整体缩放、不套用 A4/A3，严格沿用原稿页面尺寸。
- 译文页内部使用与原页完全相同的坐标系，因此右半任意元素的绝对位置可以直接取原文坐标。

## 三、逐段定位

- 解析得到的每一个内容块（标题、正文、列表、公式、图表、表格、页眉页脚……）在译文页上
  各占一块**绝对定位的区域**，位置与尺寸就是它原文坐标围出的矩形。
- 块之间互不影响：某块内容变长只在自己区域内解决，不会把下面的内容推走。
- 块按原文阅读顺序绘制，图注等叠加元素按「所属块 + 字段序号」的顺序贴出，避免互相覆盖。

## 四、文字样式来自原稿实测

| 属性 | 取值方式 |
|---|---|
| 字号 | 取该段落区域内原稿出现最多的字号（按字符数加权），标题、正文、页眉因此天然分层 |
| 字重 | 原稿该区域过半字符为粗体，或解析判定为标题层级 → 加粗 |
| 对齐 | 仅首页上半部、水平居中的块（如论文标题）居中，其余左对齐 |
| 字体 | 衬线中文字族，与正文印刷感一致；同页统一 |

字号永远是**从当前稿件量出来的**，不存在"把所有论文都按 10/9/5pt 排"的硬编码。

## 五、装不下时的让步顺序

这是整套设计的核心。每块内容按下面的顺序依次让步，尽量用最小代价换取完整：

1. **吃自己的留白**：首选用满"本块区域到下一个横向相邻块上沿"之间的空白，以及页面底部空间。
   页眉、页脚、页码例外——它们严格留在自身区域内，不向下扩张。
2. **局部缩字**：留白仍不够，就只缩小这一块的字号，二分逼近"刚好放下"的最大字号。
   **缩字是块内行为**，不会传染给邻块，也不会为一个小块压缩整页。
3. **续排到空块**：若某块被压到基准字号的 0.8 倍以下，且紧随其后是解析丢内容的空白块，
   就把该段按词/字逐个搬到空白块里，两块共用同一字号——这正对应原文跨栏或跨页分段的形态。
   续排若并不比单独缩字更划算，则整体回滚，保持原样。
   图注、页眉、页脚不参与续排。
4. **截断兜底**：以上都不行才隐藏溢出并记账，随后该块改为直接使用原稿内容（见第九节）。

图表不参与字号拟合，位置固定不动。

## 六、跨栏与跨页分段的还原

原稿一个段落跨栏或跨页时，解析结果可能把它塞进一个块，或拆成相邻两块。设计上分两步还原：

- **组版前**：用原稿文字层校正块的文字归属。若某块的文字 = 本区域可见文字 + 另一区域的尾巴，
  就按两者对齐处切开，尾巴顺延到后续的空区域（可连续传递），译文按同一比例切开一起搬过去；
  若后续块已带有这段文字，则直接去重；实在无处安放就接回原块并记录下来，**不靠位置猜文字**。
- **组版后**：即第五节的续排机制，作为几何上的第二道保险。

扫描件等没有文字层的页面不参与校正，保持解析原文。

## 七、信息量大的两类版式

### 图注、表注、子图标签

**一律不翻译**，直接沿用原稿的对应文字区域。原因：它们贴着图像边缘，译文长度一变就会溢出或错位，
历史上既丢过内容也贴错过位置。具体做法：

- 这些文字不进入翻译队列，因此不消耗翻译额度、不产生"翻译失败"告警；
- 定位方式：表注在整页范围内找，图注与子图标签只在图框上下各约 90pt 的带内找，远处正文即使
  字面完全相同也进不来；
- 换行的图注**整条一起沿用**，不会只取第一行；行距小于约 3pt 的同栏相邻行视为续行；
- 子图标签被烤进位图、文字层取不到时，按几何把范围补到图片底边；
- 定位不到就不贴、只记账，**绝不退化成"把译文重新排一遍"**。

### 表格

**保留原稿的矢量表格，只替换已翻译的单元格文字。** 不截图、不重建等宽网格。效果：

- 原表格的线条（含三线表、分组线）、列宽、跨行跨列表头、加粗与下划线全部保留；
- 数字、方法名等未翻译内容保持原字形；
- 译文写在原单元格的文字足迹内，先缩排到 0.6 倍字号，仍放不下就回填英文原文，
  再不行留空并告警——**宁可保留原文也不截图**；
- 最终右表文字可提取、可搜索。

定位不到单元格（重复文本、复杂跨行表头等）时保留英文原文，不影响整页其他单元格。

### 公式

- 块级公式按数学排版渲染，公式编号一并带出（编号与原稿对得上才扩范围，对不上宁缺勿错）；
- 行内公式若原稿文字层没有可用字符映射，就裁取原稿对应片段按原字号比例嵌入译文行内，
  随该块字号一起缩放并保持基线对齐；对不齐时保留原文，不猜。

### 图片

按原坐标裁取原稿图像贴回，不缩放、不参与整页字号拟合。

## 八、同页统一

逐块拟合完成后，再做两次全页收口，避免同页忽大忽小：

- **字号统一**：取"健康块"（拟合后仍不小于基准 0.8 倍）中的最小字号作为全页正文字号；
  被压得过狠的块保留自身字号、不拖累整页；基准字号超过全页字号 1.25 倍的大标题保留自身层级；
  图注、页眉页脚不参与。
- **行距统一**：对每块求"恰好填满自身区域"的最大行距（限 1.3–1.8 倍），取全页最小值统一应用。
  行距不越区、段落间距保持、块锚点不动。

## 九、完整性优先的降级顺序

设计上把"内容不丢"放在"版面好看"之前，降级逐级进行：

1. 缩字、续排、吃掉留白；
2. 仍放不下的块 → 该块改为直接沿用原稿内容，整页重排一次（只影响这一块）；
3. 整页组版失败 → 该页左右两半都放原页，保证文件可用并记账；
4. 失败页过多（超过 3 页且达 20%，或全部失败）→ 判整体失败并报错，不产出半成品。

翻译失败的段落**原地保留原稿内容**（避免 OCR 出的公式失真），并在记录上显示警告，不阻塞整页导出。
个别图注定位失败只记账，不影响导出。

## 十、边界与取舍

**明确不做：**

- 不把原稿改成 A4/A3，不缩放原页；
- 不追求译文与英文逐行对齐，只保证段落起点、栏宽、留白与图表位置；
- 不靠隐藏溢出来"通过"验收，不删除段落，不栅格化整表；
- 不让一个小块压垮整页，不把稀疏页强行填满。

**已知极限：**

- 表格译文需要一个系统中文字体，缺失时含矢量表格的页会整页回退原稿；
- 密集参考文献区等极端排版下，逐条对齐不完美；
- 图注定位遵循"宁可不贴也不错贴"。

## 十一、排查用的可视化

开启调试模式后，左半原页会按内容类别着色画框（同类别同色，类别名标在框角），
并单独用虚线框标出图注/表注实际沿用的裁切区域。不写块编号、不挂弹注，便于直接目视对照版式。
