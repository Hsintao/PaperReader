# 译文 PDF 排版设计

> 状态：已确认设计
> 日期：2026-09-20
> 适用范围：英文论文翻译为简体中文后的定位式 PDF、左右对照阅读和独立译文 PDF

## 1. 目标

译文 PDF 保持原稿的页面尺寸、页数、栏结构、图表位置和阅读顺序。一页原文严格对应一页译文，左右对照以段落为粒度，不要求逐行对齐。译文 PDF 脱离原文侧后仍应能够独立阅读。

排版优先级如下：

1. 内容完整，不删除正文、公式、图表或注释。
2. 一页对应一页，译文不得流入原稿没有对应内容的下一页。
3. 图片、表格线条、独立公式和出版信息保持原位置。
4. 同页中文正文具有统一、稳定的字号和行距。
5. 允许段落级位置发生小幅调整，不追求逐行对应。

## 2. 页面骨架

- 沿用原 PDF 的 MediaBox、CropBox、旋转角度和页面数量，不改成 A4、A3 或其他标准纸张。
- 原文页不修改。译文页在原页副本上移除需要替换的文字，再绘制中文。
- 普通译文 PDF 不显示解析框、文字块边框或链接注释的彩色边框；诊断框只能存在于单独的标注产物。
- 图片、图内标签、表格线条、独立公式、页码、运行页眉页脚和版权信息是不可移动区域。
- 标题、正文、列表、脚注和翻译后的图表注组成可调整文字区域。
- 每个页面先识别单栏、双栏或混合栏结构，再建立同栏文字链。文字只能在所属文字链内移动；遇到图片、表格、独立公式、栏边界或页边界即停止。

## 3. 中文字体与字号模板

应用内置并嵌入固定的简体中文宋体和黑体，所有平台使用同一套字形与度量。字体资产必须是 ReportLab 4.2.5 可加载的静态 TrueType 字体，并随许可证文件一起发布。

| 内容 | 字体 | 基准字号 | 基准行距 |
|---|---|---:|---:|
| 单栏正文 | 宋体 | 10.5pt | 1.5 倍 |
| 双栏正文 | 宋体 | 9pt | 1.5 倍 |
| 论文标题 / 一级标题 | 黑体粗体 | 16pt | 1.2 倍 |
| 二级标题 | 黑体粗体 | 13pt | 1.25 倍 |
| 三级及更深标题 | 黑体中黑 | 11.5pt | 1.3 倍 |
| 作者单位、地址 | 宋体 | 8.5pt | 1.35 倍 |
| 图题、表题、图注、表注 | 宋体 | 8pt | 1.3 倍 |
| 表格单元格 | 宋体 | 8pt | 1.25 倍 |
| 脚注、尾注 | 宋体 | 7.5pt | 1.3 倍 |

正文的首行缩进、对齐、段落边界、列表悬挂缩进和段落间距跟随原稿。短译文保持区域顶部锚点，剩余空间留白，不放大字号或拉伸行距填满区域。

粗体、强调、下划线、链接和有意义的文字颜色保留语义样式。中文斜体强调使用统一的中文强调字形，不机械倾斜汉字。

## 4. 标题和首页信息

- 论文标题和各级章节标题保持原稿的层级、占栏范围、编号和对齐方式。
- `1 Introduction` 排为 `1 引言`，章节编号不变。
- 作者姓名、邮箱、ORCID、URL、数据集名、模型名、会议名和期刊名保持原文。
- 作者单位、部门、地址及说明性出版文字翻译。
- 运行页眉、页脚、页码、卷期、版权声明和出版标识保持原文。

## 5. 正文、列表和跨区域段落

- 正文按段落翻译和对齐，不按 PDF 行逐行翻译。
- 同一语义段落跨栏、跨区域或跨页时，先合并成完整语义单元翻译，再按原稿的对应区域容量拆回。
- 跨页段落只能使用原稿中属于该段的后续页面区域，不能把本页其他内容挤到下一页。
- 普通项目符号和编号列表翻译正文，保留编号、层级和悬挂缩进。
- 摘要、关键词、致谢、附录、数据声明、利益声明、定理、证明和算法说明均翻译。
- 定理编号、算法编号、变量、代码标识符和程序结构保持原文。
- 代码清单保持代码内容、缩进和等宽结构，只翻译代码外的标题、注释性说明和自然语言标签。

## 6. 页内排版和溢出处理

一个页面按以下顺序排版：

1. 使用所属文字链中原有的空白和可压缩段间距。
2. 在不越过不可移动区域的前提下，下移后续标题、正文、列表或脚注。
3. 将全页正文统一缩小，标题仍保持相对层级；图表注和表格使用各自的字号规则。
4. 行距最低压缩到 1.25 倍，正文最低字号为 6pt。
5. 到 6pt 后仍无法容纳时，该页完整回退为原文页，并记录页面回退原因。

同页正文使用统一字号。某个密集段落不能单独变成明显更小的文字，也不能只缩一栏而保持另一栏不变。

页面回退超过 3 页且达到全文页数的 20%，或者全部页面都回退时，整篇排版任务失败，不发布译文 PDF。

## 7. 图片

- 图片、流程图、曲线图、示意图及其内部英文标签保持原始像素，不重绘、不缩放、不翻译。
- 图片在原坐标和原尺寸保留，不参与正文拟合。
- 烤进图片的 `(a)`、图例、坐标轴和文字保持原样。
- 图片外部的图题、图注和子图说明按第 8 节处理。

## 8. 图题、表题、图注和表注

- `Figure 2`、`Table 3` 等标签翻译为 `图 2`、`表 3`，编号和 `(a)/(b)` 等子图标记保持不变。
- 图题、表题、外部子图说明、表下注释和缩写解释进入翻译队列。
- 注释首先使用原注释区域；放不下时可向图片或表格相邻留白扩展，并加入同栏文字链，推动后续正文。
- 图片和表格主体不移动。注释不得覆盖图片、表格线条、独立公式或另一栏文字。
- 注释最低字号为 6pt；仍放不下时按页面回退规则处理。
- 无法可靠定位的注释保留原文并记录，不在错误位置重新绘制。

## 9. 表格

- 保留原表格的矢量线条、列宽、行高、跨行跨列、分组线、加粗、下划线和数字格式。
- 只替换可翻译单元格中的自然语言文字。数字、单位、方法名、变量、缩写和引用编号保持原文。
- 单元格依次尝试原字号换行、缩小到 6pt。仍放不下时，只将该单元格恢复为英文原文并记录。
- 表格不扩展行高，不推动正文，不截图，也不重建为等宽网格。
- 译文单元格保持可搜索、可复制。

## 10. 块内公式

块内公式指正文、列表、标题或脚注中的行内数学内容。

- 公式是不可拆分的原子元素，不翻译、不根据 OCR 或模型输出重建。
- 优先从原 PDF 对应区域裁取公式字形，并嵌入译文文本流。
- 公式随周围译文换行，可以整体移到下一行，但公式内部不能断行。
- 公式按周围中文字号等比例缩放并与中文基线对齐。
- 公式前后的自然语言和标点正常翻译。
- 若公式缺少直接坐标，依次尝试使用相邻文本跨度和原文字层恢复边界、保留包含公式的原始行切片、保留整个原始文字块。
- 任何情况下都不得为了保留周围译文而删除公式。

## 11. 独立公式

- 独立公式、多行对齐公式、矩阵、分段函数和公式编号整体保留原稿字形与位置。
- 独立公式是同栏文字链的硬边界，不参与正文缩字和重排。
- 公式编号只有在与原稿可靠对应时保留，不自行推断或补编号。
- `where`、`式中`、变量解释等公式外文字翻译。
- 公式内部的变量、单位、上下标和 `text` 内容保持原文。
- 解析结果与原页显示不一致时，以原页区域为准，不重新渲染 LaTeX。

## 12. 参考文献和引用

- `References`、`Bibliography` 章节标题翻译为 `参考文献`。
- 正文中的 `[12]`、`[3–5]`、`Smith et al. (2024)` 等引用标记保持原样。
- 参考文献条目的作者、题名、期刊、卷期、页码、DOI 和 URL 全部保持原文。
- 参考文献条目保持原列表结构、悬挂缩进和可搜索性。

## 13. 脚注和附属内容

- 内容性脚注和尾注翻译，脚注编号和回链标记保持不变。
- 页眉、页脚、页码、版权声明、卷期和出版标识保持原文。
- 无法可靠分类或定位的文字、装饰块和扫描区域原样保留，不删除，也不按正文猜测翻译。

## 14. 翻译失败和排版失败

翻译失败先执行批次重试、单段重试和安全拆分。某个逻辑块的任何分片最终失败时，整个逻辑块保留原文，不能只省略失败分片，也不能生成半中文半缺失的段落。

需要记录以下问题，但不把警告文字印入 PDF：

- 保留原文的翻译块；
- 保留英文的表格单元格；
- 无法定位而保留原文的图表注；
- 完整回退的页面；
- 导致整篇失败的页面预算。

## 15. 链接边框和诊断框

截图中紧贴图号、公式号和文献引用号的红框、绿框属于源 PDF 的 Link 注释可见边框。译文页复用源页注释后，文字位置发生变化，而链接矩形仍停留在原坐标，因此边框会套在无关的中文字符上。

译文 PDF 按以下规则处理：

- 所有 `/Subtype /Link` 注释保留 `/Rect`、`/A`、`/Dest` 和跳转行为。
- 将 `/Border` 设为 `[0 0 0]`，将 `/BS` 的 `/W` 设为 `0`，移除只用于显示链接边框的 `/C`。
- 若 Link 注释存在仅用于绘制边框的 `/AP` 外观流，移除该外观流；不处理高亮、批注、表单等非 Link 注释。
- 链接边框清理在页面覆盖、局部回退或整页回退完成后统一执行，因此译文 PDF 的每一页都遵守相同规则。
- 原始 PDF 文件保持不变。普通原文视图默认显示原文件本身；是否隐藏原文自带链接框不属于译文导出处理。

左侧蓝色、红色大框和“正文/标题”等标签属于解析诊断覆盖层：

- 只能写入独立的“原文标注 PDF”或 `layout-debug.pdf`。
- 普通原文 PDF、译文 PDF 和下载成品不得合并诊断覆盖层。
- 关闭“显示原文解析标注”后，阅读器必须重新使用原始 PDF URL，而不是继续显示缓存的标注产物。

## 16. 输出和诊断

- 译文 PDF 的文字可搜索、可复制，链接继续可点击。
- `layout-plan.json` 记录页面模板、正文字号、文字链、块状态、单元格状态和回退原因。
- 原文标注 PDF 显示解析块类型、图表注区域、不可移动区域和文字链范围，用于版面诊断。
- 界面显示结构化布局提示，并支持对翻译失败块重新处理。

## 17. 验收标准

- 输出页数、页面尺寸和页面顺序与原 PDF 完全一致。
- 译文 PDF 不显示红色、绿色或其他颜色的 Link 注释边框；链接数量、点击区域和跳转目标保持不变。
- 解析诊断框只出现在标注产物，普通译文和普通原文视图没有“正文/标题”等诊断方框。
- 图片、表格线条和独立公式区域不移动、不损坏。
- 正文没有裁切、重叠、越栏或越页。
- 同页正文采用统一字号，正常页面不低于对应模板字号，压缩页面不低于 6pt。
- 行内公式完整、基线合理，缺少坐标时不丢失。
- 图题、表题和外部注释完成翻译并位于对应图表附近。
- 参考文献条目保持原文，章节标题完成翻译。
- 翻译失败块、英文单元格和原文回退页均能在界面中定位。
- 回退页面预算严格执行：超过 3 页且达到 20%，或全部回退时不发布译文 PDF。
